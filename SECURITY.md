# Security

For a suspected vulnerability, contact the maintainer privately at
**tomelinfelipe@live.com**. Include the affected revision, impact and a minimal
reproduction using fictional data. Do not include live credentials or an entire
vault/transcript. Avoid disclosing exploitable details in a public issue before
the maintainer has had a chance to investigate.

Mercury is currently a source preview. There is no separate supported release
branch or security-response SLA. Fixes are developed on `main`.

Normal bug reports can use the repository's issue tracker. See
[CONTRIBUTING.md](CONTRIBUTING.md) for reproducible reports.
